# Miles to Kilometers Converter GUI

A simple Tkinter GUI application that converts miles to kilometers.

## Features
- Clean graphical interface
- Real-time conversion
- Input validation
- One-click calculate button

## Requirements
- Python 3.x
- tkinter (usually built-in)

## Installation & Setup
1. Clone or download the project
2. No external dependencies required

## Usage
```bash
python main.py
```

## How To Use
1. Enter the number of miles in the input field
2. Click the "Calculate" button
3. The equivalent kilometers value appears

## Conversion Formula
- Kilometers = Miles × 1.609

## Notes
- Results are rounded to 2 decimal places
- Input should be numeric
