# Turtle Race Prediction Game

A fun betting game where you predict which colored turtle will win a race across the screen.

## Features
- Interactive betting system
- Six-turtle race with rainbow colors
- Random movement simulation
- Win/loss determination
- Simple prediction interface

## Requirements
- Python 3.x
- turtle (built-in)

## Installation & Setup
1. Clone or download the project
2. No external dependencies required

## Usage
```bash
python main.py
```

## How To Play
1. When prompted, predict which colored turtle will win
2. Valid colors: red, orange, yellow, green, blue, purple
3. Race begins automatically
4. Turtles move random distances each turn
5. First turtle to reach the finish line wins
6. See if your prediction was correct

## Racing Mechanics
- 6 turtles start at left edge
- Each turn, each turtle moves 0-10 units forward
- First to x=230 wins
- Movement is random for unpredictability

## Turtle Colors
- Red
- Orange  
- Yellow
- Green
- Blue
- Purple

## Notes
- Screen is 500x400 pixels
- Turtles are evenly spaced vertically
- Case-insensitive input
- Fun way to learn random number generation
