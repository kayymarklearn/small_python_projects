# Cookie Clicker Bot

An automated bot that plays the Cookie Clicker browser game using Selenium.

## Description

A Python script that automatically clicks the cookie and purchases upgrades in the Cookie Clicker game. It runs for 5 minutes, clicking the cookie and buying the most expensive affordable upgrade every 5 seconds.

## Requirements

- Python 3.x
- Selenium
- Chrome WebDriver

## Installation

```bash
pip install selenium
```

## Usage

```bash
python main.py
```

The bot will:
1. Open the Cookie Clicker game in Chrome
2. Automatically click the cookie
3. Every 5 seconds, purchase the most expensive affordable upgrade
4. Run for 5 minutes and display cookies per second
